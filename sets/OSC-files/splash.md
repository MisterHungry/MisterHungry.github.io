### OneShot X MTG Commander (OSC)



OSC is a collection of eternal format cards based around the indie RPG [OneShot](https://www.oneshot-game.com/) by Future Cat. It's designed to be played all together as a [Commander deck](https://misterhungry.github.io/deck?id=yZVHdx7coG) led by Niko. There are 24 custom cards, all creatures, and the rest are alternate art canon reprints.



This group of cards is the first custom Magic thing I made. The original versions date back to early 2024, with a second pass in mid-2025 and then this Set Hub export in August 2026. The original inspiration for these cards can be traced to a playgroup I had in college that had floated the idea of using custom cards. Ultimately, I only got the chance to play with the deck a few times with that group, so the designs have not been fine tuned. That playgroup was generally pretty high-powered (around Bracket 4 by today's standards, although that system didn't exist at the time), so the power level of these cards reflect that (fetches, shocks, game changers, etc.).



In porting these cards over to the set hub, I did make some minor tweaks to a few of the custom designs. However, I mostly kept things the same as a product of my mindset at the time. Were I to remake this from scratch today, I probably would do some things differently (I typically play at lower power levels nowadays for one), but I think it works as it is now. Additionally, the source material is too small to support anything bigger like a full set.



This set features tagging, so you can search by card function with "tag:" followed by the tag name (typing tag: will show a list of tags that exist on the set hub). Notably, you can use tag:custom and tag:reprint to include/exclude mechanically-unique cards. For cards with the Godzilla-style alias, you can search their canon name with "alias:" followed by the name (e.g. alias:ephemerate). Don't forget to include "set:OSC" if you only want to see cards from this set.
