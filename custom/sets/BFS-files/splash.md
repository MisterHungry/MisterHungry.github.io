### Bug Fables: Everlasting Magic (BFS)

[Design Document](https://docs.google.com/document/d/1iAwazExnW4K0wgJ2zAdtNVnng0qdLlmtADU8dwDSdTs/edit?usp=sharing)



This set has a rudimentary tagging implementation, so you can search by card function with "tag:" followed by the tag name (typing tag: should show a dropdown list of tags that exist on the set hub). Notably, you can use tag:custom and tag:reprint to include/exclude mechanically-unique cards. Don't forget to include "set:BFS" if you only want to see cards from this set. Also worth mentioning tag:flagged for cards with designs flagged to be looked over more.
